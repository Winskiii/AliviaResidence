# Alivia Residence

A modern single-page application for a residential housing project marketing website. Built with React, Vite, and Tailwind CSS.

## Features

- Responsive design optimized for all screen sizes
- Dynamic unit catalog with detailed specifications
- Interactive mortgage calculator
- Modern UI components using Framer Motion animations
- SEO-friendly structure with React Helmet Async
- WhatsApp integration for direct contact inquiries

## Tech Stack

- React 19
- Vite
- Tailwind CSS
- Framer Motion
- React Router DOM v7
- Lucide React
- React Helmet Async

## Prerequisites

Make sure you have Node.js installed on your system (version 18 or higher recommended).

## Installation

1. Clone this repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Building for Production

To build the application for production, run:
```bash
npm run build
```

This will generate a `dist` folder containing the optimized static assets that are ready to be deployed.

## Deployment

This project is built with Vite and can be easily deployed to hosting services such as Vercel, Netlify, or standard web hosting. When deploying, ensure the build command is set to `npm run build` and the publish directory is set to `dist`.
